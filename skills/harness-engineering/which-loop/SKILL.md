# Which Loop

1. Find the skills the host shows this session. Read full instructions only for candidates.
2. Map capabilities to phases:
   - Observe — repository context and runtime signals
   - Plan — decisions and durable state
   - Execute — implementation or task procedure
   - Verify — tests, review, debugging, evaluation
   - Govern — permissions, approvals, audit
   - Evolve — maintenance, retuning, harness improvement
3. Pick the smallest set of skills that fit together. A phase may need none.
4. Return `phase → skill → reason`. For a gap, use the host's native workflow or report the gap.
